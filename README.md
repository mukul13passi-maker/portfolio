# Mukul Passi — Full Stack Developer Portfolio

A responsive, modern portfolio website built with plain HTML, CSS and JavaScript.

## Included
- Responsive layout for desktop, tablet and mobile
- Sticky navigation + mobile menu
- Scroll progress indicator
- IntersectionObserver reveal animations
- Skills, projects, experience and contact sections
- No framework/build step required

## Run locally
Open `index.html` in a browser.

## Customize
1. Replace concept project entries with your actual projects.
2. Add your email/LinkedIn/GitHub in the Contact section.
3. Add a profile photo if desired.
4. Deploy the folder to GitHub Pages, Netlify, Vercel, or another static host.

The portfolio intentionally describes your web-development technologies as your current learning/building toolbox rather than overstating professional experience.
